Codex 额度电量管家 {{VERSION}} · Windows 10 / 11 便携版

使用
1. 解压文件夹，双击 CodexQuotaManager.exe，无需安装或管理员权限。
2. 自动寻找本机 Codex，复用当前 Windows 用户的 Codex 登录。
3. 未找到程序时，在“设置”选择 codex.exe；登录失效时先在 Codex 重新登录。
4. 查询最新额度需要联网。不要求填写密码、验证码或 API Key。
5. 默认以电池浮窗运行：只保留电池外形，内部显示剩余百分比；鼠标停留后出现详情卡，移开后收起。
6. 若沿用旧设置未显示浮窗：在主窗口点击“小浮窗模式”，或右键托盘“显示 / 隐藏小浮窗”。
7. 更新时先右键托盘退出旧版，再运行新 EXE；重复启动不会替换仍在运行的旧进程。

托盘与退出
- 左键托盘：打开详情；右键：刷新、设置、小浮窗、退出。
- 点击详情窗口 X：收回托盘，继续运行。
- “退出管家”：停止查询、关闭管家及其创建的查询进程。不影响已有 Codex。
- 若看不到图标，请在任务栏隐藏图标区域寻找，并按 Windows 设置固定到托盘。
- 重复打开 EXE 会唤起原窗口，不会增加第二个托盘图标。

显示规则
- 按接口的真实周期长度显示；primary 不固定代表短周期。
- 多个额度桶分开展示，自动模式只比较 Codex 桶内的有效周期。
- 失败、过期、周期到期后，当前值显示未知；旧值在列表标为上次结果。
- 到期不会自动补成 100%，必须等服务端返回新窗口。
- 默认每 60 秒刷新，支持 30～3600 秒；唤醒和网络恢复后补刷新。
- 默认北京时间，可切换系统本地时区；点击周期卡片可切换托盘显示。
- 低额度按账号、窗口和重置时间去重；提醒能否显示受 Windows 通知设置影响。
- 电池浮窗默认 64×24 像素（随 Windows DPI 缩放），可拖动，双击打开详情。
- 电池内部绿色填充反映实际剩余额度；比例保留最多1位小数。
- 鼠标悬停显示紧凑面板：Codex 套餐、每个实际周期的绿色进度条、剩余百分比、重置倒计时和具体时间；可用重置卡单独一行。
- 接口返回多个额度桶时按桶分组，不合并无关模型额度；未返回的周期不额外补出。
- 面板底部可直接刷新、打开设置或退出，鼠标移入面板后可继续操作。
- 点击刷新后面板保持显示，查询中显示“刷新中…”，完成后原位更新；移开鼠标仍会正常收起。
- 主窗口隐藏时也能直接打开设置，无需先双击电池打开主窗口。
- 重置卡张数来自账号接口 availableCount，不根据公告或详情列表长度估计。未返回/查询失败显示“待更新”，不会当作0。
- 重置卡下方显示最早到期时间和倒计时，沿用面板时区。不足3天黄色，不足24小时及已到期红色。
- 只有完整有效的可用卡详情才用于最早到期计算；详情缺失、截断或无效显示“到期时间待确认”。0张显示暂无可用卡，服务端明确不失效的卡显示无到期限制。
- 到期不会在本地扣减卡数，也不跳到下一张卡的日期，等待服务端刷新确认。
- 账号、更新时间等信息可双击打开完整详情查看。
- 小浮窗右键可刷新、设置、隐藏或彻底退出；不会抢走当前应用的输入焦点。
- 数据未知时小浮窗显示“—”，具体原因在悬停详情中显示。

Tibo 重置 / 赠送消息
- 默认每5分钟检查 @thsottiaux 的公开消息，不需要 X 登录、密码或 API Key。
- 使用第三方公开 RSS 转发源，必要时回退公开监控索引，不是 X 官方 API 直连。
- 只显示最近3天（滚动72小时）与重置卡有关的候选帖子；普通额度重置/恢复消息不显示。
- 每条只有一行原文摘要，长内容省略，点击原帖查看详情。超过3天的帖子从显示和缓存移除。
- 没有符合条件的消息时，悬停隐藏整个消息区域；右键消息列表仍可检查消息源。
- 来源可能延迟、漏帖、停更。来源过旧或获取失败时不亮新消息提醒。
- 候选消息必须带有目标账号的 HTTPS X/Twitter 原帖链接，包含 banked reset、reset card、reset credit 等卡相关表述。
- 不自动判定发卡完成、账号是否符合资格、卡是否到账，也不改变额度或兑换重置卡。
- 有3天内未打开的重置卡相关消息且来源未过旧时，电池右侧端子变红；可点击端子打开消息列表。
- 鼠标悬停后可点击消息，交由默认浏览器打开 X 原帖供你确认。
- 链接提交给浏览器后记录为“已打开”，不代表已核实。失败不标记，帖子修改后重新提示。
- 右键小浮窗/托盘 → Tibo 重置 / 赠送消息，可查看更多消息及打开作者主页。
- 抓取失败只保留仍在3天范围内的重置卡消息；仅从有限时间线消失，不会判定原帖已撤回。
- 设置中可关闭消息检查，或填写自定义 HTTPS RSS（必须是 @thsottiaux）。
- 免费源当前在本机验证时内容较旧，不能保证及时完整；以 X 原帖为准。

本地文件
配置与少量额度缓存保存在 %LOCALAPPDATA%\CodexQuotaManager。
缓存仅保留上次成功时间、额度窗口；旧缓存不作为当前额度显示。
本程序不读取、复制或保存登录令牌。认证由本机 Codex 处理。
Codex 只调用 initialize / account/read / account/rateLimits/read，不创建聊天、兑换额度或切换账号。
消息原文摘要、原帖地址、已打开版本保存在同目录 tibo-news.json，不包含 X 凭据。
开启开机启动时，仅设置当前用户的 Run 注册表项；可在设置中关闭。
移动 EXE 后，如使用开机启动，请重新保存设置以更新启动路径。
退出后删除便携文件即可移除程序；需要时再删除上述配置目录。

运行条件与范围
需要 Windows 10 / 11 自带的 .NET Framework 4.8、已安装并登录的 Codex。
使用 Codex App Server 协议；未来 Codex 协议变化可能需要更新本工具。
本版包含额度监控和 Tibo 公开消息获取；消息不能代替账号实际权益查询。
程序未做发行者代码签名，Windows 首次打开可能显示未知发行者。

源代码构建
在项目目录运行 powershell -ExecutionPolicy Bypass -File .\build.ps1。
输出 dist\CodexQuotaManager.exe。
