# 隐私与本地文件

本工具通过用户已有的 Codex 可执行文件读取账号和额度，由 Codex 自己处理认证。本工具不直接打开 `auth.json`、钥匙串、密码管理器或 API Key 文件，不记录原始 RPC 数据或 helper 的 stderr。

## 本地保存

| 平台 | 目录 | 内容 |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\CodexQuotaManager` | 偏好设置、窗口位置、额度历史缓存、上次成功时间、提醒去重、消息摘要与已打开版本 |
| macOS | `~/Library/Application Support/CodexBattery` | 偏好设置、窗口位置、消息摘要与已打开版本 |

Windows 缓存不作为当前额度显示；macOS 首版不持久化账号额度。账号信息仅用于界面与同次查询一致性检查，不上传到项目自己的服务。

Codex helper 仍会按其本身实现访问和更新 Codex 的登录状态或日志，本说明不替代 Codex 自身的隐私和认证说明。

## 网络与链接

- 账号查询由本机 Codex 访问其服务。
- Tibo 功能访问文档列出的第三方公开消息源，或用户指定的 HTTPS RSS。没有 X 账号登录、Cookie 导入或 X API Key 配置。
- 消息源仅收到正常 HTTP 请求所需的网络信息，不会附加 Codex 凭据。
- 点击消息或作者主页时，由默认浏览器访问 X，浏览器自身的登录状态由浏览器管理。

## 清理

先从托盘或菜单栏退出，再删除 EXE / `.app`。需要重置偏好和消息历史时，手动删除对应本地目录。Windows 若启用过开机启动，先在设置中关闭。

## 仓库内容

仓库只包含源码、说明、合成测试数据和合成界面截图。真实账号验证输出、运行缓存、密钥和发行包已纳入 `.gitignore`。自定义消息源如含私有查询参数，应保留在本地配置，不写入文档或提交。

公开说明只保留验证通过与否，不记录验证者的账号、实际额度、卡数、到期日期或个人绝对路径。截图必须使用合成数据。

源码中的 `%LOCALAPPDATA%`、当前用户主目录、Codex默认安装位置等为通用探测规则，在运行时解析，不是某台电脑的个人路径。

Git提交还会包含作者姓名和邮箱，`.gitignore`不能隐藏这些提交元数据。公开项目应使用准备公开的昵称和GitHub noreply邮箱，并在首次提交前检查仓库级作者配置；不要把本地全局身份默认视为可公开信息。
